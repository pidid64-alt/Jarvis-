# Jarvis — локальный ассистент

Лёгкий персональный ассистент для Linux и Windows: голос, текст, окно настроек
и навыки-плагины. Рассчитан на слабые машины — ядро работает на стандартной
библиотеке Python, тяжёлые части (распознавание, синтез, слово-активатор)
подключаются лениво, когда действительно нужны.

Статус: **готовы Этапы 1 и 2** (ядро, навыки, провайдеры, терминал, голос и
окно). Окно с 07.10.2026 — локальная страница (прежнее окно на Tkinter убрано). Этап 3 — установка одной командой, `jarvis doctor` и README
для обычных пользователей. Подробности — в `docs/STAGE0_REPORT.md`.

## Быстрый старт

```bash
git clone <адрес репозитория> && cd Jarvis-
python3 -m jarvis status                 # проверить окружение и настройки
python3 -m jarvis migrate                # перенести данные старой версии
python3 -m jarvis ask "сколько времени"  # спросить текстом
python3 -m jarvis gui                    # окно: чат, навыки, настройки, журнал
python3 -m jarvis run                    # ассистент в фоне (хоткей + автопроверки)
```

Установка пакетом (появится к Этапу 3):

```bash
pip install -e .            # ядро без внешних зависимостей
pip install -e ".[voice]"   # + распознавание и синтез речи
```

## Полезные команды

| Команда | Что делает |
| --- | --- |
| `jarvis gui` | открыть окно ассистента (`--tab`, `--browser`, `--no-daemon`, `--print-url`) |
| `jarvis ask "текст"` | спросить текстом (`--no-speak`, `--yes` для подтверждения) |
| `jarvis listen` | одна голосовая команда |
| `jarvis run` | демон: хоткей, слово-активатор, автономные проверки |
| `jarvis status` | что запущено, какие провайдеры и навыки доступны |
| `jarvis skills` | список навыков, включение и выключение |
| `jarvis llm` | показать запрос к модели (`--send` — отправить и замерить время) |
| `jarvis logs` | журнал событий (`--report` — текст с вырезанными секретами) |
| `jarvis config` | где лежит файл настроек и что в нём |
| `jarvis secret set ИМЯ` | сохранить секрет в `.env` (значение не печатается) |
| `jarvis migrate` | перенести данные и команды старой версии |

## Окно

`jarvis gui` открывает окно ассистента. Если ядро ещё не запущено, оно поднимется
само, окно можно закрыть и открыть заново — ассистент продолжит работать.

Окно — это **локальная страница Jarvis** (`127.0.0.1`, случайный порт и токен),
которую показывает браузер в режиме приложения: без вкладок, адресной строки и
поиска, со своей иконкой. Такой выбор сделан ради слабых машин: не нужно ставить
ни Qt (сотни мегабайт), ни Tkinter, а вид получается современный и одинаковый на
Linux и Windows. Никаких новых зависимостей у Jarvis при этом не появляется:
страница написана на обычных html/css/js без единой библиотеки.

Пять разделов:

* **Главная** — чат: ввод текста, кнопка микрофона, история, индикатор состояния
  (ожидание / слушаю / думаю / отвечаю / нужно подтверждение / ошибка), «Стоп».
* **Навыки** — карточки с описанием, примерами фраз, правами и числом действий;
  переключатель вкл/выкл прямо в карточке.
* **Настройки** — модель и провайдеры, голос, горячая клавиша, язык, светлая и
  тёмная тема (по умолчанию — как в системе). Поля ключей скрыты, введённое
  значение уходит только в `.env`, в окно и журнал — только маска.
* **Журнал** — события с уровнями и поиском, кнопка «Скопировать для отчёта»:
  секреты вырезаются.
* **О программе** — версия, пути, лицензии сторонних проектов и кнопка
  «Остановить Jarvis» (с подтверждением): ею выключают ядро, когда нужно
  перезапустить ассистента.

Горячие клавиши: `Ctrl+L` — слушать, `Ctrl+Enter` — отправить, `Esc` — отказ от
подтверждения. Горячая клавиша Jarvis теперь делает две вещи: слушает команду и,
если окно закрыто, открывает его — раньше «пробуждение» оставалось незамеченным.

Окно можно закрыть — Jarvis продолжит работать (ядро и горячая клавиша), а
горячая клавиша снова откроет окно. Выключить ассистента целиком — кнопкой
«Остановить Jarvis» в разделе «О программе».

Цвета, отступы и размеры шрифта берутся из единого файла стиля
`jarvis/interfaces/theme.py` и повторяются в `webui/app.css`, поэтому тёмная и
светлая темы выглядят одинаково на Linux и Windows. Что и как проверено в окне —
`docs/GUI_REPORT.md`.

Если браузера нет, `jarvis gui` напечатает адрес — его можно открыть вручную
(`jarvis gui --print-url`). Флаг `--tab` открывает интерфейс обычной вкладкой, `--browser=chromium` —
каким браузером, `--no-daemon` — не поднимать ядро.

## Если модель отвечает долго

Локальные модели (llama.cpp и подобные) на слабой машине думают небыстро, и это
нормально. Jarvis ждёт ответ столько, сколько указано в **«Ожидание ответа
модели»** (Настройки → Модель и поиск, по умолчанию 60 с). Прежнее значение было
8 секунд — при нём Jarvis бросал запрос раньше, чем модель успевала ответить, а
журнал модели показывал отмену задачи. Если у вас в настройках всё ещё стоит 8,
Jarvis сам поднимет значение до 60 при первом запуске и напишет об этом в журнал.

Посмотреть, что именно уходит модели (и, по желанию, проверить ответ и время):

```bash
python3 -m jarvis llm                 # показать запрос целиком (ключ не печатается)
python3 -m jarvis llm --send          # отправить и замерить время ответа
python3 -m jarvis llm --text "включи музыку"   # с другой фразой
```

**Важно:** при таймауте Jarvis не повторяет запрос. Локальная модель в этот
момент ещё считает ответ, и повтор заставил бы её сервер отменить текущую задачу
и начать заново — вместо этого Jarvis честно сообщает, что модель не успела, и
подсказывает, где увеличить ожидание.

## Что важно знать

* **Один файл настроек** — `config.toml` (Linux: `~/.config/jarvis/`,
  Windows: `%LOCALAPPDATA%\Jarvis\config\`). Ключи в нём только ссылками:
  `${JARVIS_LLM_KEY}`.
* **Секреты — только в `.env`** рядом с настройками, права 600. Ассистент
  никогда не печатает значения ключей в консоль, журнал или окно.
* **Опасные действия** (выключение, перезагрузка, выход из сеанса, удаление
  файлов) выполняются только после подтверждения; в файле настроек есть режим
  прав `restricted` (по умолчанию) и `normal`.
* **Распознанный текст никогда не превращается в команду** — он только выбирает
  действие. Команды навыков записаны человеком заранее.
* **Интерфейсы отделены от логики**: окно, терминал и демон разговаривают с
  ядром через локальный HTTP-API на 127.0.0.1 со случайным токеном, так что
  интерфейс можно заменить, не трогая навыки. Все запросы, кроме самой страницы
  и проверки живости, требуют токен; страница убирает его из адресной строки.
* **Старая версия не удалена** — она лежит в `legacy/` и служит источником для
  `jarvis migrate`.

## Структура

```
jarvis/
  core/        логика: маршрутизация, права, журнал, миграция
  skills/      навыки-плагины (одна папка = один навык, свой skill.json)
  providers/   модель, распознавание, синтез, поиск, звук, слово-активатор
  platform/    различия Linux и Windows
  interfaces/  терминал, демон, локальный API, окно (webui + webapp)
  config/      шаблон настроек и локализация
tests/         тесты ядра, навыков, миграции, CLI, API и окна
tools/         замеры памяти, проверка контраста, макеты стиля
legacy/        прежняя версия Jarvis (не удаляется)
docs/          отчёты по этапам, макеты и виды окна, документация для разработчика
```

стиль и скрипт написаны для Jarvis, интерфейс показывает браузер пользователя.
