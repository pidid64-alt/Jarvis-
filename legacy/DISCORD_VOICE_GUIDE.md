# Discord Voice Control - Инструкция по использованию

## 📞 Голосовые звонки в Discord

Теперь Jarvis может звонить вашим друзьям в Discord! Просто скажите:

### Примеры команд:

#### Звонок Фену (уже настроено):
- "Позвони Фену"
- "Звони Фену в дискорде"
- "Вызови Фена"

#### Звонки другим друзьям:
- "Позвони Алексу" → звонит пользователю alex
- "Позвони Диме" → звонит пользователю dima
- "Позвони Максу" → звонит пользователю max
- "Позвони Ивану" → звонит пользователю ivan
- "Позвони Кате" → звонит пользователю kate

#### Видеозвонки:
- "Видеозвонок Фену"
- "Позвони Фену с видео"

#### Управление звонком:
- "Положи трубку" → завершить звонок
- "Заверши звонок"
- "Ответь на звонок" → принять входящий звонок

#### Управление микрофоном и звуком:
- "Замьють в дискорде" → вкл/выкл микрофон (Ctrl+Shift+M)
- "Оглуши в дискорде" → вкл/выкл звук (Ctrl+Shift+D)
- "Включи камеру в дискорде" → включить видео (Ctrl+Shift+V)
- "Демонстрация экрана в дискорде" → показать экран (Ctrl+Shift+S)

## 🔧 Как это работает:

1. **Jarvis проверяет**, запущен ли Discord
2. Если нет — **автоматически запускает** его
3. **Открывает быстрый поиск** (Ctrl+K)
4. **Вводит имя** друга
5. **Выбирает первый результат**
6. **Инициирует звонок** (Ctrl+')

## ⚙️ Настройка своих контактов:

Отредактируй файл `~/jarvis/discord_contacts.json`:

```json
{
  "contacts": [
    {
      "name": "fen",
      "display_name": "Фен",
      "username": "fen"
    }
  ]
}
```

### Добавление нового друга:

Скажем, хочешь добавить друга Сашу с никнейм "sasha123":

1. Открой `~/jarvis/discord_contacts.json`
2. Добавь в список:
```json
{
  "name": "sasha",
  "display_name": "Саша",
  "username": "sasha123"
}
```

3. Затем добавь команду в `commands.json`:
```json
{
  "id": "discord_call_sasha",
  "phrases": [
    "позвони саше",
    "звони саше в дискорде"
  ],
  "command": "bash $HOME/jarvis/scripts/discord_call.sh sasha123",
  "response": "Звоню Саше в Discord.",
  "speak_output": false,
  "timeout": 10
}
```

## 📝 Созданные скрипты:

- `discord_call.sh <username>` - универсальный звонок
- `discord_video_call.sh <username>` - видеозвонок
- `discord_hangup.sh` - завершение звонка
- `discord_message.sh <username> <text>` - отправка сообщения
- `setup_discord_contacts.sh` - настройка контактов
